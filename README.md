魔法
以有知性生物的靈魂產生的非粒子非波動 被稱呼[魔力]的物質為原料
通過對世界萬物任何東西的信仰產生的奇蹟 以上被人們稱呼為魔法
魔力沒辦法被人類的科技發現 只有察覺且能用魔法的人才能理解魔力
信仰的東西任何東西都可以 只要是喜愛與狂熱的情感也都算在信仰內
神 宗教 名人 偶像 二次元 MIKU 物質 石頭
只要人真心地去信仰 且能操作魔力 就能以此發動魔法
然後人與人同時信仰一個東西 他們無意識散發的魔力與信仰交織在一起後
就會形成[共同迴廊]
共有迴廊
所謂共同迴廊 就是集體對於某一特定主題的信仰構成的迴廊
世界觀下的基督教 神明之類的信仰都有他們的共同迴廊
而成為共同迴廊一份子的魔法使換來的是 魔法帶來的奇蹟更加的穩定
這種通稱為{共有術式}

    2.獨有迴廊
那麼當然有無法加入共有迴廊的衰鬼
這種人無法加入共有迴廊的理由為 靈魂特殊性高 無法接受加入共有迴廊
那麼靈魂特殊性高的意思講白點就是  討人厭的社交障礙患者
這種人沒辦法加入共有迴廊 但是他們有一個特權 是製造只屬於自己的迴廊
通稱 獨有迴廊
所謂獨有迴廊 是只有自己能用的術式構成的集合體
術式效果全都自己設定 使用規則也是自訂
